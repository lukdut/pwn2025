### `pwn2025.1`

Разделённая версия позволяет выбрать в BitTorrent-клиенте только нужные
диапазоны длины паролей. `.xz`-файлы можно передавать Hashcat напрямую —
предварительная распаковка не требуется. Одновременно можно указать несколько
файлов.

```console
hashcat [параметры] <файл-хеша> pwn2025.1_8_9.txt.xz
hashcat [параметры] <файл-хеша> pwn2025.1_8_9.txt.xz pwn2025.1_10a.txt.xz
hashcat [параметры] <файл-хеша> pwn2025.1/
```

Последняя команда использует все файлы словаря из каталога `pwn2025.1`. Точная
команда и набор параметров зависят от типа хеша и режима атаки.
